# 0010. Русский язык — канонический для документации

[English version](0010-russian-canonical-documentation.en.md)

Статус: принято (2026-11-03)

## Контекст

Изначально документация следовала апстримной схеме: английская каноническая версия в `.md` и русская в `.ru.md`. Пользователь работает с проектом преимущественно на русском и выбрал обратный приоритет. Нужно сменить схему целиком, включая существующие документы, ссылки и автоматические проверки, а не только объявить новое правило.

## Решение

Каноническая русская версия каждого документа находится в `.md`. Английская версия того же документа находится рядом в `.en.md`. Это относится к README, AGENTS, ADR, архитектурным документам, roadmap и companion-шаблону pull request.

Документы содержат перекрёстные ссылки. Существующие английские `.md` переименованы в `.en.md`, русские `.ru.md` стали каноническими `.md`. Отсутствующие английские переводы `architecture` и `roadmap` добавлены.

Consistency-тест рекурсивно проверяет наличие пары для каждого документа. Специальные GitHub-файлы используют каноническое имя, необходимое самому GitHub, а английская версия получает суффикс `.en.md`.

## Альтернативы

- **Сохранить английский каноническим.** Уменьшил бы изменения, но противоречит выбору пользователя.
- **Только русский язык.** Проще поддерживать, но теряется доступность для англоязычных читателей и существующие переводы.
- **Оба языка в одном файле.** Не требует companions, но удваивает длину и усложняет синхронное редактирование.
- **Изменить правило только для новых документов.** Сохранил бы старые ссылки, но оставило бы репозиторий с двумя конкурирующими схемами.

## Последствия

- (+) Основная документация читается на языке пользователя, английские переводы сохранены.
- (+) Однозначная схема имён проверяется автоматически; Git сохраняет историю переименований.
- (−) Каждый документ требует синхронной поддержки двух версий.
- (−) Внешние ссылки на прежние английские `.md` и русские `.ru.md` должны быть обновлены; локальные ссылки исправлены этой миграцией.

# 0009. Временно запускаем CI только на Ubuntu

[English version](0009-temporarily-run-ci-on-ubuntu.md)

Статус: принято (2026-11-03)

## Контекст

ADR-0005 ввело матрицу Linux/macOS/Windows. При настройке Pages macOS jobs долго стояли в очереди, а две были abandoned. Это блокировало deployment без своевременной обратной связи. Пользователь попросил временно оставить только проверки, нужные для разработки эмулятора и публикации Pages.

## Решение

Временно убрать матрицу ОС из `rust`, `ts` и `native` и запускать их только на `ubuntu-latest`. Сохраняются Rust-тесты, TypeScript/tooling-проверки, Ubuntu Tauri сборка, WASM и браузерный E2E, dependency-проверки, aggregate `ci` и Pages build/deploy workflow.

Aggregate принимает только `success` и `skipped`. Выбор jobs по путям не меняется, защита ветки по-прежнему требует только `ci`.

Это временное операционное решение, а не отказ от поддержки macOS и Windows. Матрицу нужно вернуть после стабилизации deployment или возобновления кроссплатформенной работы, оформив восстановление новым решением.

## Альтернативы

- **Сохранить полную матрицу.** Сохраняет покрытие, но оставляет разработку заблокированной очередями раннеров.
- **Полностью отключить native builds.** Быстрее, но удаляет полезные Ubuntu Tauri IPC и проверку сборки desktop.
- **Запускать non-Linux только вручную.** Снижает нагрузку, но требует отдельного триггера и более сложной конфигурации.
- **Принимать abandoned как успех.** Делает aggregate ненадёжным и позволяет merge без проверок.

## Последствия

- (+) CI быстрее отвечает для ядра, web, desktop Linux и Pages.
- (+) Настройка обязательной проверки ветки не меняется.
- (−) Регрессии macOS и Windows временно не обнаруживаются автоматически.
- (−) Восстановление кроссплатформенных проверок требует явного последующего изменения.
